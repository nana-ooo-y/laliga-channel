# LaLiga Channel

スペインサッカーの選手やクラブを紹介するWebサイトです。

Web制作を学び始めた頃に制作したサイトを、
現在のHTML / CSS / JavaScriptの知識を活用して
リニューアルしました。

## 制作背景

以前制作したサイトでは、選手情報をHTMLに直接記述していたため、
情報の追加や変更がしにくい構造になっていました。

また、スマートフォン表示や検索・絞り込み機能にも
対応していませんでした。

そこで、過去作品を現在の知識で設計し直すことを目的として
リニューアルしました。

## 主な機能

- 選手カードの動的生成
- 選手名による検索
- ポジションによる絞り込み
- 検索結果が0件の場合のメッセージ表示
- レスポンシブデザイン

## 使用技術

- HTML
- CSS
- JavaScript

## 工夫した点

選手情報をJavaScriptのオブジェクト配列として管理し、
DOM操作によって選手カードを動的に生成しています。

また、`filter()`と`includes()`を使用して、
選手名検索とポジションによる絞り込みを実装しました。

CSSではFlexboxとGridを使用し、
メディアクエリによってスマートフォン表示にも対応しています。
